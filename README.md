# SafeRise (GBV Awareness Prototype)

SafeRise is a lightweight, browser-based prototype app designed to raise awareness about Gender-Based Violence (GBV) in South Africa.  
It focuses on **prevention, youth engagement, and anonymous peer support**, using a **minimalistic black-and-purple design** (GBV awareness colors in South Africa).

---

## 🎯 Goals
- Provide a **lightweight prototype** (HTML, CSS, JavaScript only).
- Work **offline or with minimal data usage**.
- Engage **youth through gamified quizzes**.
- Offer **anonymous peer support** via a simple chat-like interface.
- Integrate **local services** (shelters, police, NGOs in Johannesburg/Gauteng).
- Educate users on **signs of abuse, rights, and safe exit strategies**.

---

## 📂 Project Structure
The app consists of **three files**:

1. `index.html`  
   - Main structure of the app.  
   - Sections: Homepage, Emergency Button, Resources, Quizzes, Peer Support.  

2. `style.css`  
   - Minimalistic design using **black (#000000)** and **purple (#800080)**.  
   - Branding footer: *“Powered by Brelinx (brelinx.com)”* in **light grey (#cccccc)**.  

3. `script.js`  
   - Adds interactivity:  
     - Emergency button popup.  
     - Quiz logic (questions, scoring).  
     - Anonymous chat simulation (local storage).  

---

## 🎨 Design Guidelines
- **Minimalistic layout**: clean sections, lots of whitespace.  
- **Color scheme**:  
  - Background: black  
  - Accent: purple  
  - Text: white  
  - Branding footer: light grey  
- **Typography**: Sans-serif (Roboto, Inter, or Poppins).  
- **Branding**: Small footer text “Powered by Brelinx (brelinx.com)”.

---

## 🚀 Features
- **Emergency Help Button**: Simulates calling for help (popup alert).  
- **Resource Cards**: Links to shelters, police, NGOs.  
- **Gamified Quizzes**: Interactive awareness challenges.  
- **Anonymous Peer Support**: Chat-like interface (local storage only).  
- **Educational Section**: Signs of abuse, rights, safe exit strategies.  

---

## 🛠 How to Run
1. Download the three files (`index.html`, `style.css`, `script.js`).  
2. Place them in the same folder.  
3. Open `index.html` in any browser.  
4. The app runs offline, no backend required.
